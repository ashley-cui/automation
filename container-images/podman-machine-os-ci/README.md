# Podman-machine-os CI image

Built and pushed to `ghcr.io/podman-container-tools/podman-machine-os-ci:<tag>` by
`.github/workflows/build_container_images.yml` on every release tag.

Used by the [podman-machine-os](https://github.com/podman-container-tools/podman-machine-os) and
related projects for CI. Not intended for use outside those contexts.
